# VirtuaPets: MyPets Denver mock clinic

This directory is the branch-specific entry point for the private MyPets Denver
simulation. The branch is `virtuapets/denver-mock-clinic`; it remains part of
the VirtuaPet repository and does not represent a separate production product.

See [operating plan and setup evidence](../../docs/simulations/DENVER_MOCK_INITIAL_SETUP.md).

Run the current isolated checks:

```sh
node --test simulations/denver-mock/*.test.mjs
node simulations/denver-mock/plan.mjs
```

The build now includes fail-closed simulation tools for deterministic fictional
pet fixtures, short least-privilege consent grants, a Denver Mock Stripe sandbox
acceptance run, and labeled email-thread evidence. The tools keep generated
results under the ignored `results/` directory and reject live Stripe keys,
unapproved recipients, unlabeled messages, and unsafe clinical content.

`config.json` documents the safe simulation defaults. `clock.mjs` is tested independently and is not wired into VirtuaPet or Stripe. The local ignored `.env.participants.json` contains the user-authorized recipient roster; it must never be included in a site bundle or Git. No passwords are stored. Do not enable mail or seed a shared live tenant from this scaffold.
