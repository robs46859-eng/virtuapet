# VirtuaPet Phase 4 Pilot Specification

## GibiWorld spatial integration

VirtuaPet publishes only signed, entitled, immutable manifest versions. The client verifies the signature, downloaded GLB checksum, expiry, revocation, minimum client version, units, scale, axes, laterality, bounds, and rollback target before rendering. Failure blocks the asset and records a redacted audit event. GibiWorld remains a separate runtime and is not modified by this repository phase.

Desktop simulation precedes tablet AR and named-headset testing. Physical acceptance requires visible scale, orientation, laterality, camera, interaction, performance, entitlement-revocation, and rollback evidence on each device. Clinical assets additionally require the existing veterinarian approval and source-traceability gates.

## Pet-assistant robot alpha

The alpha is a low, stable, one-floor, remotely supervised platform. It may perform owner-controlled presence, patrol, docking, and enrichment tests. Local collision, cliff, heat, current, wheel-stall, privacy, network-loss, and emergency-stop controls must operate without cloud availability.

Medication, feeding, restraint, stairs, exterior doors, unsupervised animal interaction, and safety-critical autonomous decisions are excluded. Simulation and empty-room tests precede controlled supervised animal exposure. No readiness claim is allowed without physical test logs and incident review.

## Partner ground-travel pilot

The pilot uses vetted human-operated partners. Required records include handler verification, owner consent, custody transitions, route, climate, rest, water, feeding, medication instructions, emergency destination, jurisdiction evidence, and incidents. Regulation results must link to current primary sources and require human review when ambiguous or stale.

Autonomous live-animal transport and live-animal drone transport are excluded.

## Drone research

Drone work is limited to simulation and permitted property logistics with qualified operators. It must not carry live animals. Airspace, remote-identification, operator, payload, privacy, weather, emergency, and jurisdiction requirements must be reviewed for every test location.

## Holographic and spatial rendering research

Use the technically accurate term for the tested display: AR, mixed reality, stereoscopic, light-field, or volumetric. “Holographic” remains a research description unless the named hardware produces that display method. Track frame rate, frame-time percentiles, resolution, model fidelity, latency, thermal behavior, memory, occlusion, scale, and color/material consistency on named hardware.
